## Execution and stopping

1. Run domain-analyst@7 through the ordinary owned worker and firewall. Every
   query, read and finish is model-selected. Do not inject tool actions/results,
   prompts or evaluator hints. QueryContext itself is not a success requirement;
   actual source/inventory evidence acquisition and disclosure are.
2. A first unmet finish may produce the V7 host's protected refusal feedback and
   an ordinary subsequent invocation within existing shared budgets. This is
   part of this versioned protocol, not permission for harness retries. Persist
   its actual response usage, immutable disclosure and refusal before continuing.
   A second unmet finish terminates atomically as obligations_unmet without a
   result or third repair invocation. Do not reset limits or restart a task.
3. Record failed, cancelled, exhausted and unknown outcomes without replay. An
   honest insufficient-evidence result is a distinct outcome, not a successful
   requested source-and-inventory control. A security/transport failure is not
   recoverable completion feedback. Reserved FirewallRefused is never fabricated.
4. Gate auditor dispatch on analyst mechanical checks and a frozen post-run
   semantic review. If either fails or is unreviewable, record why and skip the
   auditor. Do not modify the original analyst receipt with review conclusions.
5. If analyst passes both, dispatch evidence-auditor@7 once with its independently
   revalidated obligations and saved parent result. Parent history cannot satisfy
   auditor obligations. Retain source guards throughout. Stop at its terminal or
   unknown outcome. No selective rerun, repair outside the worker, changed budget
   or alternate model after observing either role.

## Required durable evidence, per role

- Request4 and envelope1 bind the original canonical mixed intent; input6,
  disclosure4, result5 when present, StoredTask2 and summary/detail4 agree.
- Required source and inventory attempts come from actual admitted tool actions,
  with ordered response/event/ledger identity and charged shared budgets. Attempt,
  acquisition, actual supplied representation and cited support stay separate.
- A supported finish satisfies every explicit obligation against its actual
  finishing disclosure. Inventory identity/body binds the frozen archive and
  context; it creates no source citation. Exact retained source is supplied and
  source-supported claims cite its captured occurrence. T3/InferredWeak remains.
- An insufficient-evidence outcome requires the V7 completed-attempt contract and
  empty findings. It may be honest while failing this control. Acquired-then-
  redacted evidence stays acquired but cannot falsely satisfy supported completion.
- Refusals, if any, remain durable; known usage is charged once, unknown usage
  stays unknown. Refusal feedback is protected and disclosed on the next ordinary
  call. No requirement forces a refusal when the model reads first.
- Fresh connections revalidate detail/result/ledger/events and archives. Retained
  source access works without the original checkout. Graph facts are unchanged.
  This is coordinator reopen evidence, not native process restart or forgetting.

## Independent review and receipt

Freeze the V6 rubric's initializer-level scope: the chosen span alone cannot prove
surrounding guarded-return/function behavior. Review broader claims only against
additional source actually supplied. Check coverage-limit statements against the
actual supplied inventory, attribution of parent history, and absence of false
completeness/freshness claims. Keep the rubric out of model-visible materials.

Original bytes can support review only when actual disclosure proves matching
representation hashes. For transformed representations, use bounded authorized
post-firewall review evidence or mark the claim unreviewable; never infer the
supplied content from different original hashes. Missing evidence cannot pass.

Retain immutable per-role run receipts and separate independent reviews. Report
mechanical, semantic and delivery results independently, including absence of
required evidence and skipped stages. Avoid exporting raw prompts/responses or
sensitive spans by default. Publish evidence hashes and exact implementation
identity. No result reclassifies any prior failed run.

Vendure primary acceptance, native restart, disposable-capture forgetting, broader
negative cases and independent auditor acceptance remain distinct #598 gates.
A follow-up harness issue/PR should implement this protocol only after interface
cross-review; any live invocation still requires the applicable user authorization
and frozen pre-invocation receipt. This draft itself grants none.

## Frozen classification and review (revision 2)

This is n=1 per role, with the auditor skipped if the analyst fails its gate. It
is one synthetic end-to-end observation, not an estimated success rate. No extra
runs may be added after outcomes are observed. Any larger experiment needs N and
its aggregation rule frozen before the first call of that separate experiment.

| Per-role outcome | Control result |
| --- | --- |
| supported, zero refusals | Pass only if mechanical and independent semantic checks both pass; report first-shot supported |
| supported, exactly one refusal | Pass only if both checks pass; report supported after one refusal separately |
| insufficient_evidence | Fail the requested source-and-inventory control, even when honest and mechanically valid |
| obligations_unmet | Fail; retain no-result terminal and refusal evidence |
| failed, cancelled, exhausted or unknown | Non-passing; retain the exact distinct status and reason |
| reviewer evidence unavailable | Unreviewable and non-passing; never infer semantic success |

Every role receipt records refusals_before_finish separately (or null when no
finish was admitted), alongside total durable refusal count and terminal status.
No rate aggregates or first-shot claims combine the two supported categories.

Freeze exactly one retained-source obligation and one recorded-inventory
obligation for the analyst, and independently resolved one source plus one
inventory for the auditor. Record each canonical envelope and hash. Record the
sampling configuration, including temperature, seed or explicit unset, and
context length beside the verified runtime/model manifest identity. Omitted or
unverified runtime fields remain labeled as such; do not invent defaults.
The neutral question contains no evidence identifiers or expected conclusions.

The independent semantic reviewer is Claude (trueline-claude-agent[bot]), named
before execution. The sealed immutable analyst receipt precedes review. Claude
receives only the frozen rubric and admissible evidence, not Codex's semantic
interpretation. Claude records the gating decision in a separate signed review;
the original receipt is not edited. Apply the same independence to auditor review.
Reviewer unavailability stops at the gate rather than substituting self-review.

A harness, fixture or receipt defect is an invalid-run classification only when
proved from durable evidence before interpreting the outcome. Preserve that run
and record the defect evidence separately; assign no model-outcome classification.
Any replacement needs a new frozen run definition describing the defect and fix,
independent review, and applicable owner authorization. A surprising or failed
model result is not evidence of a harness defect and cannot justify a replay.
