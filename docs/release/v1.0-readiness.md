## 6. How v1.0.0 is cut

Tags are automation-owned (ADR-0015, [releasing.md](../releasing.md)). There is no manual tag step: merging the reviewed **Version packages** PR is the release decision. Automation then creates the immutable annotated tag after the exact `main` commit's complete suite passes, and the Release workflow publishes the signed build.

1. Merge the pilot-blocker and pilot-defect fixes. Done: #1603, #1608, #1609 and #1612. Until v1.0.0 is tagged, nothing else merges to `main`, so #1602 work stays on branches.
2. Cut the verification release, an **interim `0.59.x`** (owner decision, 2026-11-01), through the normal Version packages PR. Record its commit, CI run and artifact hashes here.
   - **Cut 2026-11-02:** [v0.59.0](https://github.com/true-line/cartograph/releases/tag/v0.59.0), Version packages #1607 merged at `728416a309a965ebac6068c83690fd708bdea7ee`, tag object `7919e15c`, Release run 41373761130 succeeded.
