## Evidence by criterion

### 1. Large-estate run

`docs/showcases/scale.md` records a deterministic ingest of six pinned
repositories, among them `openmrs/openmrs-core`, `apache/kafka` and
`kubernetes/kubernetes`, with wall time, peak memory and what was not
recovered for each lane. It is reproducible with
`node scripts/bench-ingest.mjs`. The criterion asks for OpenMRS or 50 or
more repositories; the page covers the first form. Whether this page is
accepted as the run of record is an approval question, not an engineering
one, and is left open here.

### 2. SimpleLogin pilot on a release build

`docs/showcases/simplelogin.md` records the deterministic recovery of the
three SimpleLogin repositories scored against the project's own API
reference. That run uses a release test binary, not a packaged release
build. No recorded pass on a packaged build is in the repository.

### 3. Frozen rubric and real-model acceptance

Not met. The rubric freeze (#598) and the real-model run (#1710) are open.
ADR-0066 (proposed, #1888) states that the run may use any runtime of the
role, a local model included, and records which.

### 4. Curated projection

Met on `main` by #1746 (merged in #1858): an accepted proposal is in the
Workbench, in a `best-effort` export (`curated.md`) and in an MCP read
under one curated revision, with the base graph hash unchanged (SPEC-12,
ADR-0061).

### 5. Document catalogue

Met: catalogue version 1.0, `docs/DOCUMENT-CATALOGUE.md`, approved
2026-11-17 (#1747, #1856).

### 6. Agent-authored document

SPEC-15 and ADR-0064 are implemented on `main` (#1866, #1869 and the
#1874 stack): the draft record, the admission rule, the `section-writer@1`
drafting run, the D1 document and the Workbench review. #1873 holds the
expected set written before any run (`docs/acceptance/w13/expected.json`)
and the scorer. AC-0670 stays open until `docs/acceptance/w13/scores.json`
is committed from a real drafting run, scored by a reviewer who did not
produce the drafts. T-0670 is reserved for it.

### 7. Living documentation

Met on `main` by #1875 to #1880 (SPEC-17, ADR-0045, AC-0671 to
AC-0675): changed and missing cited facts are computed by set comparison
of recorded and current content hashes, an accepted draft whose cited
fact changed is marked stale in place, and the same inputs give the same
marks (T-0672). Contradiction by a newly added fact is not decided
(ADR-0045) and is not part of the criterion.

### 8. Existing documentation as evidence

SPEC-18 and ADR-0065 are implemented in #1881 to #1887 (AC-0676 to
AC-0681): documentation files and sections are T0 facts, an exact
reference that resolves is a `MENTIONS` link, and a route or file
reference that no longer resolves is a `Drift` fact in
`drift_register.md` citing the reference and what it was compared with.
`documentation-evidence.md` lists the links. Met on `main` (#1750).

### 9. Rebuild handoff

SPEC-16 and the review form (`docs/acceptance/w17/`) are in #1874. A
bundle is what the existing export writes, read under that definition, so
no new producer is required. Review 1 (2026-11-20,
`docs/acceptance/w17/review.md`) took an export with no drafted section
and found it not sufficient: three questions silent, rules stated as
source expressions, 1 of 26 expected statements stated in domain terms,
and 6 of 8 entry points in no document and no gap row. The pilot
proper uses an export made after the drafts of criterion 6 are reviewed;
that review has not happened. `bundle-manifest.md` states the bundle's as-of and lists its
files by part (AC-0682). A draft whose statement names a path or code
symbol of a fact it cites is not staged (AC-0683).
