## 6. How v1.0.0 is cut

v1.0.0 is never cut from an unverified build.

1. Merge the pilot-blocker and pilot-defect fixes.
2. Cut a verification release: a release candidate (`v1.0.0-rc.N`) or an interim `0.59.x`.
3. Rerun the full SimpleLogin pilot on that signed build, step 8 included, and run the #598 real-model acceptance against it. If anything fails, fix it, cut the next candidate and rerun.
4. Record the passing build's commit and results in this report. The owner approves.
5. Tag v1.0.0 on that same verified commit. Only the version bump may differ. If any other change lands, the pilot runs again.
