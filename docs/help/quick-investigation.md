# Quick investigation

While Cartograph is focused and receives the shortcut, press **Cmd+Space** on
macOS to open quick dispatch, or use **Cmd+J** when its fallback is enabled in
Settings. On Windows and Linux press **Ctrl+J** (Ctrl+Space is left alone
because it switches input methods there). macOS may intercept Cmd+Space;
Settings always has an **Open quick investigation** button as a
pointer-accessible entry to the same dialog.
The dialog starts one of the host catalog's supported Domain Analyst or Evidence
Auditor simple investigations. It also supports Standard completion specialists
(@7, Spec Writer, and Gap Triager) when the host advertises their compatible
policy. For these roles, select at least one currently recorded inventory from
the displayed scope; the dialog never selects evidence for you. It uses the
existing investigation coordinator, provider availability, saved history, and
cloud consent flow; it is not a streaming chat.

Quick dispatch accepts a question within the existing 2,048-byte limit and
uses the current standard graph scope. Evidence-specific source requirements
remain in the full Investigations composer. Findings are T3 / InferredWeak
proposals. Quick dispatch keeps its evidence selections separate from the full
composer draft. If a start outcome is uncertain, retry the same saved
request to recover its identity; the dialog does not claim success until the
host returns a durable investigation ID.

After a confirmed start or retry, Quick Dispatch opens that exact saved task in
Agent Chats. A refused or uncertain start stays in the dialog; use **Open
Investigations** there to recover a different pending request.

Until your first confirmed quick dispatch, a **Dispatch to an agent** pill at
the bottom of the workspace names the shortcut and opens the same dialog. Hide
it with its close button; **Show the "Dispatch to an agent" hint** in Settings
turns it back on. It is not shown in Settings, Help or the ingest flow.
