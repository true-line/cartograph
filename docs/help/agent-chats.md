# Agent Chats

Review saved specialist conversations and open their findings. The list uses
the same saved investigation history as Investigations, including its search,
active filter, and **Load older saved tasks** continuation. The selected task
shows its saved question, producer identity, and typed result reference when
those records are available. Older tasks without a persisted conversation
remain identifiable and can still be opened in Investigations.

Use the result link to open that exact task in Investigations, where its saved
findings and citations are displayed. Opening conversations does not start a
task or change the composer or an uncertain start request. This surface shows
persisted task conversations; it does not provide freeform assistant messages,
streaming, or multiple conversation panes.
