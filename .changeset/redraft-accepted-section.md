Lets you re-draft a stale section. "Re-draft this section" on an accepted draft that is stale or unresolvable now asks Cartograph for the request, which is refused with a reason when the draft is current or a re-draft of it is already waiting. The draft the run stores names the accepted draft it replaces. The accepted draft stays printed until you accept the re-draft, and is then kept as replaced. Rejecting a re-draft changes nothing else and allows another. An existing review store is upgraded in place the first time it is opened, with every stored draft kept.
