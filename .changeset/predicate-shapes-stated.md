D1 §1.5 Rule cells now state a check a method runs on its receiver, a sum compared with a method's value, a flag bit, and membership in a method's value, instead of a Gap row. The last answer of a Python method that returns `True` or `False` elsewhere is now a rule even when the method's name has no `is_`, `has_` or `can_` prefix ("Otherwise, the user's lifetime or active subscription is true when the user's active subscription is set").
