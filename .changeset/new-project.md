Projects: the Workspace's **New project…** sets the loaded system aside (its recovered facts, sources, findings, investigations, drafts, reviews, decisions and job history) and restarts Cartograph empty, so you can load a different repository without reinstalling. **Projects** lists every project and switches between them with no re-ingest, renames them and deletes parked ones. Settings, provider keys, run limits, the local model and installed adapters are shared by every project.
