Product specification sections can now be composed in one model call from what Cartograph already knows. The section composer is handed a D1 section as the export compiles it, with its capabilities, operations, rules and flows, plus the facts that section cites. It writes dense prose claims that cite only those facts. Claims that name a source file or code symbol are left out. The rest are staged as a draft for review. A cloud composition sends only the payload you approved. On SimpleLogin, a trial of this approach turned §1.3 to §1.6 into 48 cited claims for about $1.
