Recover what a system changes, not only what it refuses (#1998). Python assignments through an attribute and calls to repository functions are now rule facts with the branch conditions around them. D1 §1.5 lists them under each capability as "Changes", and §1.2 shows whom a guard makes the request act as. On SimpleLogin this states how an API key or a signed-in session becomes the acting user, and that deleting an alias moves it to the trash for the configured number of days or deletes it.
