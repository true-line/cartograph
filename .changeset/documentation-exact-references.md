Links existing documentation to the facts it names. A code span or link in a Markdown section that names exactly one recovered fact, by its id, a file path, a route written as a method and a path, or a unique resource, channel, entity, service or workload name, is now a `MENTIONS` link from that section to the fact, citing the reference. A reference that matches nothing or more than one fact is not linked.
