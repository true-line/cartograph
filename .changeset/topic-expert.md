Ask an area's expert. The Spec Workbench lists the areas the knowledge phase grouped the code into; choose one and ask a question, and `topic-expert@1` answers from that area's part of the product specification in one model call. You review the exact payload before it is sent. An answer is labelled as the agent's reading, cites the specification rows it rests on, says what the briefing does not hold, and names a neighbouring area to ask instead when the question belongs there.
