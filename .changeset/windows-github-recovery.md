GitHub recovery works on Windows for repositories with long branch names: a clone now fetches only the default branch, so a deeply nested remote branch can no longer fail it with "path too long", and long working-tree paths check out. The GitHub field also accepts pasted forms such as `github.com/owner/repo`, `www.github.com/…`, `http://…`, a `…/tree/main` view, GitHub's `?tab=readme-ov-file` suffix, and wrapping brackets or quotes. A refused address now shows what was entered and the accepted forms, or says to choose "Local folder" for a path.
