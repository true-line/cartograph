Recover infrastructure from code that has no IaC. Proven browser storage (IndexedDB, Cache Storage, Web Storage), SDK clients (AWS SDK v3, Firebase, Supabase, Stripe, MongoDB, Postgres, Redis, Prisma) and auth clients (Auth0, Clerk, NextAuth, Cognito) become observed `Resource` nodes under Atlas → Infrastructure, each linked to the code that uses it. The client table is registry data that extension files can add to.
