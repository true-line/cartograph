Subsystem areas stay inside one repository. When a system is ingested as several repositories (a server with a browser extension and a mobile app), each repository is now grouped on its own, so areas no longer mix server and client files and the server's areas are the ones it has when ingested alone. A subject two repositories both have is one area per repository, where the larger keeps the name and the other adds where its files are (for example "Alias" and "Alias (core/model)"), and shared code is listed per repository.
