Subsystem areas read more like the system's real subjects. An area is now named for the term most of its files share instead of a rarer word a few of them carry (for example "Metric" instead of "Backend and metric", "Event bus" instead of "Bus and event"). Files that only resemble each other weakly are no longer published as an area with an invented name, an area that held two subjects is split in two, and two areas with the same name are merged. A widely used file that is named for a subject (for example `alias_utils`) now stays in that subject's area instead of moving to "Shared code", which kept the Alias area from disappearing. In the product specification, capabilities that no HTTP request starts (scheduled jobs, operator commands, mail listeners) are listed under the area of the code they start, instead of under "Other capabilities".
