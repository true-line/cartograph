The product specification's §1.4 "Acceptance criteria per capability" now lists, under each capability, the recovered tests that exercise its operations: the scenario as the test author named it (snake_case test names read as words), the test file, the operations it requests and a citation for each reference. On Vendure `packages/core` the section goes from a pointer to other files to 1,924 scenarios; on SimpleLogin, 296.
