# Visible fixture loader

`load_fixture_bundle(root)` reads fixed `inputs.json`, `leakage.json`, and `labels.json` plus the retained paths declared in inputs. It admits at most 8 MiB per manifest, 32 MiB total declared encoded data, and 64 KiB per retained span. Rooted no-follow handles reject symlink descendants and selected nonregular files. All retained sizes are checked before retained-body copies. The frozen schema in `schema.json` has SHA256 `6d0477903fabc2f08ece74e1a79049374fa0262570e24b4a40aee4143c087428`.

`LoadedFixtureBundle` has private construction/fields, no Deserialize implementation, and immutable `inputs`, `leakage`, `labels`, `digests`, `source_bytes` accessors. Public DTO construction/deserialization grants no validation or gate authority. `canonical_json` implements the bounded integer-only/ASCII-key RFC8785 subset; `sha256` is a fixture-format digest, not an embedding-space identity replacement.

The loader validates closed shapes and required-null fields, recursive duplicate keys, bounds, schema constants, exact family identity, hashes, source spans/corpus references, sorted unique identities, complete group/label coverage, target-universe references, explicit unknown/no-match handling, exclusive-label basis, deterministic group buckets, and observable duplicate source/query/target lineage grouping. Undeclared semantic near-duplicates and the truth/completeness of evidence require independent review and are not proven by hashing.

`unverified_corpus_references()` explicitly exposes graph/capture digest **references**, not verified graph/capture bytes: the frozen manifest has no paths for those documents. A host must independently supply and compare observed corpus bindings before any evaluation receipt can be compatible with live inputs. Separately retained mechanism corpus documents can be independently checked against those references without upgrading the bundle to a quality dataset.

All bundles have the frozen `visible_mechanism_fixture` purpose. Evaluation split means visible mechanism evaluation, never blind quality holdout. Calibration receives calibration labels only; prediction must not receive evaluation labels. An independently controlled store/runner is necessary for actual holdout secrecy. This consistency wrapper cannot authenticate fixture authors, prove label independence, select a threshold, or authorize gate acceptance.

The crate-private `load_independent_dataset(root)` uses the same structural schema with an explicit expected root purpose of `independent_evaluation`; the public fixture loader stays fixed to `visible_mechanism_fixture`. Only the three root purpose constants and the independent leakage-rule version constant are overridden during schema checking. Raw documents and their hashes are never rewritten. A mixed-purpose bundle fails both routes. This private loader still establishes consistency only: purpose text alone cannot authenticate an independent dataset or authorize scoring/admission. The separate reviewed host boundary must bind the observed corpus, trusted reviewer/author/implementer separation, policy order and all exact hashes.


Independent datasets require `partition_policy.version: "catalogue-leakage@1"`. Visible fixtures still require their frozen `sha256-group-bucket@1` value and all original fixture grouping behavior; the frozen JSON Schema bytes are unchanged. Both use the pre-existing bucket algorithm/domain (`cartograph-t2-split@1`); the new version identifies leakage semantics, not a salt or group search. Its changed leakage-document digest is included in the policy commitment before calibration.

Under the independent rule, supervision is per case. Labelled identities are that case's positive target IDs and explicit hard-negative IDs. Their definition sources, hop sources and label-origin evidence form the exact `related_source_ids` union for a group. Shared supervised identities, source references/spans/bodies, query bytes and hop owners must remain in one group. A target labelled in one case may still be an **unlabelled catalogue occurrence** in another group; that occurrence neither joins groups nor becomes a negative. Catalogue-only sources must not be padded into related-source lists. Unknown contributes no target label or negative; its supplied query/evidence remains grouped. Undeclared semantic near-duplicates still require independent review.
